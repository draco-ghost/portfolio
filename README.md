## 🚀 Getting Started

Follow these steps to run the project locally.

## Prerequisites

Make sure you have installed
- XAMPP
- Git

## installation

1. Clone the repository

```bash
git clone https://github.com/draco-ghost/portfolio.git
```

2. Move the project into XAMPP's htdocs directory

For a standard Windows installation, copy or move the project folder to:

```text
C:\xampp\htdocs\portfolio
```

3. Start Apache
Open the XAMPP Control Panel and start the Apache module.

If the project uses a database, also start MySQL and configure the required database settings.

4. Open the website

Visit the following URL in your browser

```text
http://localhost/portfolio/
```

## 💻 Development

- Edit PHP, HTML, CSS, and JavaScript files in your preferred code editor.
- Keep the project inside XAMPP's htdocs directory for local development.
- Refresh your browser to see your changes.
- Access PHP files through Apache using localhost; opening them directly as files in your browser will not execute PHP.
